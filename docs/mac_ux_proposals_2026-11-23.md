# 新用戶走查改進提案（Mac，2026-11-23，已對照程式碼複查）

來源：模擬器全新安裝（系統繁中），選「英文母語、學法文」，加入 French Basic 3000 Words，逐頁截圖。每一項都對照了程式碼與 docs/mac_inbox.md 裡的既有決定；標「需 owner 決定」的是會改到之前特意做的設計。只提案，做不做由 Windows／owner 決定。

## 可以直接做（小）

| # | 位置 | 看到的情況 | 建議 |
